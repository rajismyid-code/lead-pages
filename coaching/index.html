Coaching institutes, ఈ ఒక్క prompt save చేసుకోండి 📚

Parent రాత్రి "New batch ఎప్పుడు? Fees ఎంత?" అని WhatsApp చేస్తారు. Demo class కి వచ్చారు, తర్వాత ఎవరూ call చేయలేదు. ఈ prompt మీకు 3 ready messages రాస్తుంది: enquiry reply, demo reminder, demo తర్వాత follow-up.

1. AI prompt (ChatGPT / Gemini లో paste చేయండి)

You are the front-desk assistant of a coaching institute in Andhra Pradesh / Telangana.
Write 3 short WhatsApp messages to PARENTS in simple Telugu mixed with common English words. Warm, respectful, clear.
RULES: never promise ranks, marks or results. Never mention other students. No pressure lines like "seats filling fast" unless I say it's true.
1) ENQUIRY REPLY (to "New batch ఎప్పుడు? Fees ఎంత?"): next batch start date and timings, fee and how it can be paid,
   one line on how classes run, and invite them to a free demo class with 2 time options.
2) DEMO CLASS REMINDER (the evening before): date, time, address/landmark + Maps link, what the student should bring,
   ask them to reply YES to confirm.
3) AFTER-DEMO FOLLOW-UP (2 days after the demo): thank them for coming, ask what the student felt about the class,
   offer to answer any question, and give the batch start date. No pressure.
Each message under 60 words, max 1 emoji. Use [ ] for anything I must fill in.
Institute: [name] · Courses: [ ] · Next batch: [date, timings] · Fee: [₹ , instalments?]
Address/landmark: [ ] · Maps link: [ ] · Contact: [ ]

2. 3 ready messages ([ ] లు fill చేయండి)

Enquiry reply
నమస్తే 🙏 [Institute] కి message చేసినందుకు thanks. [Course] new batch [date] నుంచి, [timings]. Fee ₹[ ] ([instalments]). ముందు ఒక free demo class చూడొచ్చు: [Sat 10 AM] లేదా [Sun 5 PM]. ఏది బాగుంటుంది?
Demo reminder (ముందు రోజు సాయంత్రం)
నమస్తే [Parent name] గారు, రేపు [date] [time] కి [Institute] లో demo class ఉంది. Address: [landmark], Maps: [link]. Notebook, pen తీసుకురమ్మనండి. Confirm చేయడానికి YES అని reply చేయండి.
Demo తర్వాత (2 రోజులకు)
నమస్తే [Parent name] గారు, demo class కి వచ్చినందుకు thanks 🙂 [Student] కి class ఎలా అనిపించింది? ఏమైనా questions ఉంటే అడగండి. New batch [date] న start అవుతుంది.

3. ఎలా వాడాలి

WhatsApp Business లో వీటిని quick replies గా save చేయండి (Settings → Business tools → Quick replies; shortcuts ఉదా: /fees, /demo, /thanks). Message రాగానే "/" type చేసి, [ ] లు మార్చి పంపండి.

Bonus: demo రోజే సాయంత్రం ఒక్క "Thank you for coming" message. Prompt లో "4) demo రోజు thank-you message కూడా రాయి" అని add చేయండి.

🔒 Privacy rule: students పేర్లు, marks, phone numbers ChatGPT లో paste చేయకండి. Prompt కి institute details మాత్రమే కావాలి. మీకు number ఇచ్చిన parents కి మాత్రమే messages పంపండి.
